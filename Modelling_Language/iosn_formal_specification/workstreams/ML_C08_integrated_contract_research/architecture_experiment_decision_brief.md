## 1. Three research hypotheses

A is a modular Requirement/Semantic Registry linked to separate Input/Process/Math/Output/Verification profiles. B is an integrated typed Contract Metamodel/AST. C uses federated standard-oriented views with controlled canonical reference identities. All depend on the same tool-neutral meaning (source/requirement/process/data/math/output/verification/evidence) but no physical central registry service or serialization is mandated.

| Aspect | A Modular | B Integrated typed | C Federated standard views |
|---|---|---|---|
| Identity | Explicit cross-profile resolver/version tuple | Central typed graph and semantic revisions | One canonical authority ledger with versioned view mappings |
| Verification | Dedicated profile joins and model evidence | Typed verification/evidence nodes | Distributed verification views and common evidence ledger |
| Math model | Separate mathematical contract profile | Typed equation/index/guard representation | Conceptual domain math view; standards adapters not yet native |
| Version risk | Inconsistent profile release tuples | Broad central schema migration | Lossy mapper, duplicate authority, version drift |
| Potential benefit | Independent profile release cadence | Strong central type consistency | Reuse of existing standard tool ecosystems |
| Need to verify | Resolver and cross-profile semantic fidelity | Real operator completeness and coupling cost | Native standards parser and lossless roundtrip |

## 2. What ML-C06 actually observed

ML-C06 PR #50 head 2d306845a2855a9956e7dc685df423e304ebbb52 recorded 45/45 expected custom representation classifications each for A, B and C (135/135), plus eight expected semantic-change rejections each (24/24). The same 528/1323 C02 frozen graph, C04 B01–B15 toy cases and **common semantic test kernel** were used. Initial B09 checker-field-name error caused 132/135 and was corrected before 135/135 rerun. This is not evidence of three independent native mathematical implementations, real SysML/ReqIF/GEMS/LinkML/SHACL parser compliance, production integration cost or model physics.

A shared canonical *semantic responsibility* is essential, but that does not select A, B or C or a single runtime/database/service. D6-A requires independent tool realisations of one scientific specification, not conversion of Tool A's LP into Tool B.

## 3. Conditional evaluation outcomes

- A remains plausible when independent domain teams can manage versioned profiles with an unambiguous cross-profile resolver. A may fail if profile tuples and cross-links become brittle.
- B remains plausible when centrally controlled typed AST semantics include genuine M01–M18 generated operator constraints and change coupling is affordable. B may fail if one minor domain change forces widespread unmanageable migration.
- C remains plausible if **real** standards-native parsers and bidirectional mappings preserve all 48 SR, 18 P, 87 B01-D, 20 process-only, 38 T, authority, math, optionality and evidence. C fails if view divergence or dual-ownership loses mandatory semantics.
- No measured maintenance economics, native generated E04 matrix comparisons or standard conformance currently differentiates these sufficiently for an ADR.

## 4. Required discriminating experiments before a later ADR

1. Independently test native parser/serializer roundtrip for at least two proposed standards slices and deliberately break authority, units, P15 guards and process-only IDs.
2. Generate real E04 toy LP constraints/coefficients for M01 shared x, M04/M05 physical KCL/KVL and market link, M08 stages/F_y, M13 storage, M15 H2 and optional M18 OPF. Add actually mutated native rows and independent oracle.
3. Separately evaluate E-FEAS, E-OPT and E-OBS with matched projections, multiple-optima counterexamples and risk-based D4.
4. Mutate source clause, CY/UTC units, mathematical operator and control scope; record actual release compatibility, migration effort, stale-evidence invalidation and recovery across A/B/C.
5. Preserve exact 48/18/87/38 inventory, C02 typed graph and evidence request/actual evidence separation in all representations under pinned source identity. Require new owner and external scientific review for real conformance, not for draft conceptual experiments.
