## 1. Typed identity, revisions and authority

Canonical semantic identity is the tuple (namespace, stable_id, semantic_revision, effective methodological profile). An instance additionally requires actual source-content identity, study year, external CY ID, UTC interval, space, carrier, scenario/variant, stage and run where applicable. A content revision is not source approval, and a Git blob is not a qualified original data file.
