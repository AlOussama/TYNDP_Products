# Language and evidence limitations
- Closed finite native fragment; solver-specific variables, objectives, unrestricted macros, arbitrary sparse supports and undocumented units are excluded.
- Explicit duration/basis/weights required; no arbitrary calendar/DST, general time aggregation or hidden defaults. No global proof of all guard conflicts or universally complete behavioral service.
- Native actual evaluation differs from structural admission and independent oracle replay. Equal outputs, source hashes or passing regressions do not establish independent model conformance.
- C3 A/B sources derived from one design; MUT-11 alternate research representation is not the identical C23 mutation. P5 is an independently replayed CBA synthetic stress profile, not full methodology. IoSN is a conceptual target, not a full native implementation.
- No real PyPSA, Antares, Sienna integration, empirical usability, real-world source authenticity, external approval, general E4/E5 or production readiness.
- Legacy migrations are bounded examples with incomplete provenance guarantees; C4 general quantitative minimality and maintainability cannot be inferred from code line counts. OWNER_TBD persists.
