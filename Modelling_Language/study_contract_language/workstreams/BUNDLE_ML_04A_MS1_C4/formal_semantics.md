## 1. Abstract metamodel and concrete authoring
The sole mathematical authority is the native public Program of the exact admitted canonical package (C2 mathematical package versions 0.1–0.3). Each package includes canonical math, a typed symbol/domain/quantity binding and source/audit identities. C1 preflight and C2 boundary checking are mandatory. The outer representation is strict JSON, with qualified IDs and explicitly ordered axes. The new implementation has two levels:
- **Definition** (definition.py, `c2-closure-definition-0.2`): study identity/version/OWNER_TBD, StudyFrame, method slots, pinned source bytes, requirements. The frame contains the study question, domains, scopes, components, ports, referents, observables, inputs, outputs, relations, authorities, variations, chronologies, information sets, slots, processes, comparisons, relation domains, context fields and external report requests. Each slot contains an admitted native package, profile, source reference, symbol bindings, assertions, policy/state/comparison references, verification requests and optional ledger definition. Static admission requires no observed data, solver or generator.
- **Instance** (`c2-closure-instance-0.2`): exact definition semantic reference, slot method/package identities, PRESENT or MISSING_DATA and snapshot digest, actual dataset, case context, witnesses, contribution rows and expected event sets, event definitions, variation disclosure and data provenance receipts, categorical context rows and non-executed external report receipts. Instance identity is a separate externally supplied digest. Missing data blocks evaluation; it is not assigned zero.
- **Package** (`c2-closure-contract-package-0.3`): definition, optional instance, computed receipt. `definition.export` and `definition.reimport` recompute and compare canonical bytes against externally supplied roots. Static result is STATIC_VALID, data NOT_EXECUTED, conformance NOT_PROVED. Graph-level research package `c2-closure-study-contract-0.2` supports actual finite checks.
- Requirements: included and environment subjects, spatial and functional scopes, data contract provenance/license/access/reproducibility/quality/missing-data/conversion, process roles PREPROCESS/EVALUATION/POSTPROCESS/VALIDATION, normativity, model declarations, comparison and time policies. Refer to `metamodel.json`, `schema.json`, and the actual executable examples CL17/CL23; structural schema is not the semantic validator.

## 2. External obligations and physical semantics (BLK-01/03)
C2 metadata reuses R1 n1r table/reference and quantity semantics and C1 quantity algebra. Component, port and referent identity remains separate from native symbol identity. Every external port has component, direction, quantity, axes and authority. Connections require compatible OUT/IN (or bidirectional), matching carrier atoms, physical dimensions, sign, temporal basis, and axes; no inferred sign reversal. Observables bind typed identity or native expression projection; derived projection must actually depend on the declared subject. Native symbols have explicit INPUT, OBSERVABLE, EXTERNAL_WITNESS, METHOD_PARAMETER or DERIVED_EXPRESSION roles; all bindings and slots must be covered, no raw extension AST. Every declared scope and subject reference is checked. External obligations express invariant or observation, not internal decision variable.
An assertion uses a native predicate reference, outer semantic role and modality, scope, ordered binders, optional finite coordinate restrictions, guard, assumption IDs, authority references. Guard uses literal TRUE/FALSE/UNKNOWN (unknown reason required), native input-only guard predicate or strong Kleene NOT/AND/OR over guards. Guards are structurally checked even if false. Native condition definedness is not Bool3 truth. An assumption is DATA/TECHNICAL/ENVIRONMENT; only input/parameter-dependent assumptions may gate a guarantee. A/G is pointwise over declared scope: false or nonapplicable assumption excludes point; unknown assumption blocks the point; true activates guarantee. Scope and binders exactly cover required domains and guard/assumption dependencies. Safety and prohibition require universal quantification; permission is not proof; a service/capability requires FORALL request then EXISTS response, complete declared request coordinates and nonvacuous applicability. Capability observes existence of a finite satisfying response. Service additionally requires explicit actual response witness for each applicable request and matching snapshot/source identity; absent witness BLOCKED. Neither yields universal behavioral proof. Independent model/tool/formal evidence requests stay NOT_EXECUTED unless actually evaluated at the stated level. Research approvals cannot be promoted. Conflicting obligations cannot be resolved by implicit override or missing guard. Direct identical unconditional positive/prohibited obligations are rejected (CL25). No implicit override; arbitrary symbolic overlapping-guard consistency remains NOT_PROVED. Authorized research-only method-slot replacement is handled by composition.py with separately pinned authorization and unchanged protected obligations; arbitrary imports, implicit precedence and normative approvals remain refused. Exact same-frame inputs and ordered graph do not establish global consistency.

## 3. Native mathematical, temporal and relation execution (BLK-02)
Reuse existing C1/C2 admission, canonicalization, exact quantity and finite consumer; extend public Program dispatch only for previously admitted Translate, WindowSum, ParameterDefined, JoinedCondition, CountComparison. Translate positive offset looks backwards with declared zero or wrap edge; window uses the declared trailing interval indices, clips or wraps explicitly. Physical type of zero is computed by existing static quantity checker, not by evaluating an inactive row. Definedness tests presence on full admitted support (False remains defined); CountComparison counts native binary truth; joined conditions require exact single lookup cardinality. Both native boolean branches evaluated; no unsupported expression hidden behind short-circuit. Complete data support is mandatory. Static admission and runtime support are distinct.
Chronology intervals explicitly list positive rational hours, ordered labels, start/end and duration; no calendar inference. State boundaries reference native predicates at first/last coordinates; cyclic states require distinct endpoint equalities and a native equality between explicitly typed endpoint symbols. Information partitions use original R1 stage coverage and refinement rules, and nonanticipativity compares actual finite decisions inside each information cell. Each native relation has qualified row/key support bound to actual rows, exact Cartesian key domain or explicit enumerated tuple-key domain. Optional topology columns bind to declared physical connection edges and ports. No absent rows interpreted as zeros. Arbitrary sparse masks/partitioned shift and calendar/DST conversion remain explicitly unsupported; native solver variables, objective, constraints, macros and duals excluded. Typed quantity registry and physical/monetary conversion retain original C1/R1 semantics. Exact units not in admitted registry must be explicitly converted with source and justified conversion factor or refused; Annual cost rates can be projected to an explicitly declared period amount with a pinned integration rule (EUR/year * period_years -> EUR); raw source values and period basis are retained. The native registry is not silently extended. External qualitative or other unexecuted quantity reports remain declarations with no numeric value.
