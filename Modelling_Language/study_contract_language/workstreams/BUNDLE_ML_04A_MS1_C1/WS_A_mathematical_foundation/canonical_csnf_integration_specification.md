# Canonical boundary

M3 wraps native canonical YAML plus source, semantic and audit hashes. Reimport reconstructs and compares every field; arbitrary leaf extensions rejected. M2 maps a limited observable comparison into existing R1 measure/compare AST; arithmetic expression mapping is unsupported, and full C21 acceptance of the leaf is not claimed.
