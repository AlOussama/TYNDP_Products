# Reuse-first A/B/C/H0 comparison (not ranking)

- A independent CSNF core: simple research graph and typed guard checks available in restricted P1, incomplete predicate/domain semantics and adapter burden.
- B KerML/SysML-based CSNF: promising typed part/port/requirement/membership built-ins, additional metadata/profile and native tests required.
- C federated CSNF: preserves native local tool semantics but audit and typed alignment are not yet demonstrated.
- H0 small native SysML profile: required falsifiable comparison remains **unresolved**.

GEMS offers component/connection reuse but not a universal external behavioural contract; mathspec supplies normalization and expression AST patterns but is not an independent proof of equivalent optimization models. No factual claim of lower implementation cost without execution metrics.
