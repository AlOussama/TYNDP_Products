# Metrics and methods
Study metric references an existing typed output; unit, basis, carrier, axes and computation remain owned by the C4 output signature and pinned native method. Verification metric references existing assertion or comparison policy (Boolean semantics; do not introduce a redundant numeric counter). Validation metric references external report request. Role is explicit: calculated study output is not an acceptance decision. Numeric and relative tolerances must be native mathspec conditions in admitted assertions with explicitly authored reference and zero policy; this profile does not invent a default tolerance. Method changes use C4 composition and exact external root pinning, not a second math AST. General metric/criterion binding and authorized profile replacement require additional evidence.
