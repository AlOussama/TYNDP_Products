# Traceability
Derivation = directed parent edge from system requirement to study/system requirement. Allocation = existing target references and scope. Verification and validation = typed test-to-requirement links; evidence points back to versioned test and requirement refs, definition/instance/method identities. No new relation DSL. Dependency through native method graph retained. Satisfaction = derived assessment not a static edge. Requirement target coverage must be exact for required requirements. No cycles or unresolved refs. Multi-target semantic implication, finer-scope refinements and authorized requirements replacement not established.
