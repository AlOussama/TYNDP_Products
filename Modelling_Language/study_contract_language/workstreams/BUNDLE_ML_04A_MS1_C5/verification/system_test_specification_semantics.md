# System Test Specification – bounded profile
Tests have stable ID/version, objective, requirement links, metric reference, scope, oracle source, method and evidence role. Test subject and acceptance criterion are reused from the metric's typed target. Inputs, scenario context, quantities and preconditions are inherited from C4 Definition/Instance. Native assertion evaluates C4 scoped guard/assumptions; native comparison reuses C4 actual counterfactual evaluation. Coverage derived from declared context axes and actual submitted rows, not a declared Boolean. External review is referencable, not executed or trusted by this profile. Native output alone cannot satisfy a test. No production orchestrator, general proof or scientific validation authority. Coverage and exact root binding are required. Diagnostic attribution restricted to uniquely owned comparison and exact native code. Missing/incomplete support blocks, known native counterexample fails. Other/internal rejection blocks; not expected failure.
