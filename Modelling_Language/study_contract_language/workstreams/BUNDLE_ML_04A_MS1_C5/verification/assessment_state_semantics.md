# Assessment states
STATIC_VALID is design admission, not a result. Execution is EXECUTED, BLOCKED or NOT_EXECUTED; applicability is TRUE/FALSE/UNKNOWN. Verdicts PASS/FAIL/BLOCKED/INCONCLUSIVE/NOT_EXECUTED are independent of expected test-harness outcomes. A native finite contradiction is FAIL only if attributable to the tested target. Internal errors propagate. Requirement assessment: FAIL dominates, then INCONCLUSIVE, BLOCKED, all N/A, all pass or N/A, otherwise NOT_EXECUTED. Study validation is separate, never inferred automatically from system PASS. Overall contract conformance remains NOT_PROVED and owner OWNER_TBD.
