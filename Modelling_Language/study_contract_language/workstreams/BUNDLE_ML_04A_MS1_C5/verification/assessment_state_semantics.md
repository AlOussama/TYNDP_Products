# Assessment
Separate static admission, execution, applicability, verdict, requirement assessment and overall NOT_PROVED. PASS only for attributed native result with required finite support. FAIL is a finite counterexample. BLOCKED means missing data/evidence or unavailable valid native receipt. INCONCLUSIVE covers unknown/conditional native assertion and contradictions. NOT_EXECUTED has no execution. False applicability separately recorded with native reasons; unknown is not false. Declared evidence cannot produce PASS; a contradiction downgrades a positive/negative computed result. Expected negative unit-test success is not a contract PASS. Overall conformance is never promoted. External independent review confirmation not implemented.
