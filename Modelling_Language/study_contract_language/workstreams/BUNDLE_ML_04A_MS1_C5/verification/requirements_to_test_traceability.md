# Traceability
Study Requirement <- parents of System Requirements -> targets in typed C4 scope -> Metric -> criterion -> TestSpecification -> pinned Instance request -> native receipt -> computed evidence -> requirement assessment. The registry admits unique qualified IDs and versions, rejects cycles, missing or wrong-kind references, target mismatch and uncovered mandatory target sets. Trace is not proof of semantic entailment; the current exact-scope profile does not express arbitrary scope refinement. C5 computed evidence binds both definition and instance pins and method identities; old claims cannot be reused after a root change.
