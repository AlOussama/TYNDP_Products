# Authoring grammar
Inherit C3 c3-authoring-0.1 A/B structural grammar without changing lexer/parser. A: study_contract quoted-version { definition Object instance Object }; Object ::= { (Key : Value ;)* }; Value ::= Object | List | QuotedString | Integer | true | false | null; List ::= [ comma-separated Values ]. B: strict JSON with schema, definition, instance. D5/I5 objects follow final_schema.json. No floats as outer literals; native mathspec grammar inside pinned leaf. Concrete complete examples emitted by actual VT28 in CI; this document is a grammar supplement, not a full parser specification.
