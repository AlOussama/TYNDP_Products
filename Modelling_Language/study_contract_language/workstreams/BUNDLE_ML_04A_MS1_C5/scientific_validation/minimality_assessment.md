# Minimality and reuse
C4 alone has external obligation and verification records but no versioned independent requirement registry and many-to-many test trace. Composition alone can carry labels, but cannot reject missing/incorrect requirement links or classify study versus verification metrics. C5 adds three design record roles (Requirement, Metric, TestSpecification), declared evidence and derived computed evidence/assessment; zero math primitives. Existing targets and all math reused. Controlled removal of requirements/criterion/metric/coverage/oracle_ref is executed in test_controlled_ablation. This proves these fields are necessary for the chosen explicit profile validation, not a proof of globally minimal language or a fully equal-scope alternate implementation. Adapter count one new profile module; inherited C4 adapter complexity unresolved.
