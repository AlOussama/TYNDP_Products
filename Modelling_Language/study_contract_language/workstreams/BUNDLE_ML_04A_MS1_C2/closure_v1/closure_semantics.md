# Targeted C2 closure — controlled semantic language specification
**Status: NON-NORMATIVE / RESEARCH ONLY.** ADR-C1-COMP-01 retained. This is a versioned outer contract layer over the pinned native mathspec canonical specification, not an optimization-model authoring language, solver, second mathematical normal form or alternative parser. The root C2 specification, results and original identities remain historical and unchanged. This document and the new manifests record the targeted continuation, not a normative release.

## 1. Abstract metamodel and concrete authoring
The sole mathematical authority is the native public Program of the exact admitted canonical package (C2 mathematical package versions 0.1–0.3). Each package includes canonical math, a typed symbol/domain/quantity binding and source/audit identities. C1 preflight and C2 boundary checking are mandatory. The outer representation is strict JSON, with qualified IDs and explicitly ordered axes. The new implementation has two levels:
- **Definition** (definition.py, `c2-closure-definition-0.2`): study identity/version/OWNER_TBD, StudyFrame, method slots, pinned source bytes, requirements. The frame contains the study question, domains, scopes, components, ports, referents, observables, inputs, outputs, relations, authorities, variations, chronologies, information sets, slots, processes, comparisons, relation domains, context fields and external report requests. Each slot contains an admitted native package, profile, source reference, symbol bindings, assertions, policy/state/comparison references, verification requests and optional ledger definition. Static admission requires no observed data, solver or generator.
- **Instance** (`c2-closure-instance-0.2`): exact definition semantic reference, slot method/package identities, PRESENT or MISSING_DATA and snapshot digest, actual dataset, case context, witnesses, contribution rows and expected event sets, event definitions, variation disclosure and data provenance receipts, categorical context rows and non-executed external report receipts. Instance identity is a separate externally supplied digest. Missing data blocks evaluation; it is not assigned zero.
- **Package** (`c2-closure-contract-package-0.3`): definition, optional instance, computed receipt. `definition.export` and `definition.reimport` recompute and compare canonical bytes against externally supplied roots. Static result is STATIC_VALID, data NOT_EXECUTED, conformance NOT_PROVED. Graph-level research package `c2-closure-study-contract-0.2` supports actual finite checks.
- Requirements: included and environment subjects, spatial and functional scopes, data contract provenance/license/access/reproducibility/quality/missing-data/conversion, process roles PREPROCESS/EVALUATION/POSTPROCESS/VALIDATION, normativity, model declarations, comparison and time policies. Refer to `metamodel.json`, `schema.json`, and the actual executable examples CL17/CL23; structural schema is not the semantic validator.

## 2. External obligations and physical semantics (BLK-01/03)
C2 metadata reuses R1 n1r table/reference and quantity semantics and C1 quantity algebra. Component, port and referent identity remains separate from native symbol identity. Every external port has component, direction, quantity, axes and authority. Connections require compatible OUT/IN (or bidirectional), matching carrier atoms, physical dimensions, sign, temporal basis, and axes; no inferred sign reversal. Observables bind typed identity or native expression projection; derived projection must actually depend on the declared subject. Native symbols have explicit INPUT, OBSERVABLE, EXTERNAL_WITNESS, METHOD_PARAMETER or DERIVED_EXPRESSION roles; all bindings and slots must be covered, no raw extension AST. Every declared scope and subject reference is checked. External obligations express invariant or observation, not internal decision variable.
An assertion uses a native predicate reference, outer semantic role and modality, scope, ordered binders, optional finite coordinate restrictions, guard, assumption IDs, authority references. Guard uses literal TRUE/FALSE/UNKNOWN (unknown reason required), native input-only guard predicate or strong Kleene NOT/AND/OR over guards. Guards are structurally checked even if false. Native condition definedness is not Bool3 truth. An assumption is DATA/TECHNICAL/ENVIRONMENT; only input/parameter-dependent assumptions may gate a guarantee. A/G is pointwise over declared scope: false or nonapplicable assumption excludes point; unknown assumption blocks the point; true activates guarantee. Scope and binders exactly cover required domains and guard/assumption dependencies. Safety and prohibition require universal quantification; permission is not proof; a service/capability requires FORALL request then EXISTS response, complete declared request coordinates and nonvacuous applicability. Capability observes existence of a finite satisfying response. Service additionally requires explicit actual response witness for each applicable request and matching snapshot/source identity; absent witness BLOCKED. Neither yields universal behavioral proof. Independent model/tool/formal evidence requests stay NOT_EXECUTED unless actually evaluated at the stated level. Research approvals cannot be promoted. Conflicting obligations cannot be resolved by implicit override or missing guard. General overlapping-guard consistency/proof and authorized override algebra are not provided; exact same-frame inputs and ordered graph do not establish global consistency.

## 3. Native mathematical, temporal and relation execution (BLK-02)
Reuse existing C1/C2 admission, canonicalization, exact quantity and finite consumer; extend public Program dispatch only for previously admitted Translate, WindowSum, ParameterDefined, JoinedCondition, CountComparison. Translate positive offset looks backwards with declared zero or wrap edge; window uses the declared trailing interval indices, clips or wraps explicitly. Physical type of zero is computed by existing static quantity checker, not by evaluating an inactive row. Definedness tests presence on full admitted support (False remains defined); CountComparison counts native binary truth; joined conditions require exact single lookup cardinality. Both native boolean branches evaluated; no unsupported expression hidden behind short-circuit. Complete data support is mandatory. Static admission and runtime support are distinct.
Chronology intervals explicitly list positive rational hours, ordered labels, start/end and duration; no calendar inference. State boundaries reference native predicates at first/last coordinates; cyclic states require distinct endpoint equalities and a native equality between explicitly typed endpoint symbols. Information partitions use original R1 stage coverage and refinement rules, and nonanticipativity compares actual finite decisions inside each information cell. Each native relation has qualified row/key support bound to actual rows, exact Cartesian key domain or explicit enumerated tuple-key domain. Optional topology columns bind to declared physical connection edges and ports. No absent rows interpreted as zeros. Arbitrary sparse masks/partitioned shift and calendar/DST conversion remain explicitly unsupported; native solver variables, objective, constraints, macros and duals excluded. Typed quantity registry and physical/monetary conversion retain original C1/R1 semantics. Exact units not in admitted registry must be explicitly converted with source and justified conversion factor or refused; Annual cost rates can be projected to an explicitly declared period amount with a pinned integration rule (EUR/year * period_years -> EUR); raw source values and period basis are retained. The native registry is not silently extended. External qualitative or other unexecuted quantity reports remain declarations with no numeric value.

## 4. General methods, data and contribution lineage (BLK-04/05)
MethodProfile is reusable definition (native mathematics + typed signatures/roles, ranges, weight policies, source/version, counterfactual pair policy, output/intermediate partition). Study identity and bound domain member lists are excluded from method-definition identity but retained in mathematical binding/instance identities. No method-specific constants in validator; explicit SUM_ONE or SUM_RANGE subprobability within [0,1], DURATION_WEIGHT tied to actual chronology and distinct TIME_WEIGHT. Static checks refactored from existing WS_B validator; old numeric checks retained in execution. Generic data and profile signatures, exact source bytes, full bound snapshot and case context are checked. Actual method swaps remain existing C2 controls. Multiple slots each publish explicit outputs; dependent inputs bind exact producer values, declared graph dependencies match actual upstream references and cycles/drift/duplicate producers reject. No implicit priority, unapproved version change or override.
Paired counterfactuals reference typed case relation and actual observed series. Declared exogenous and project field universe is disjoint; compare actual bound input-row digests, require exogenous equality, enforce only explicitly allowed project fields changed, verify case-context digest against actual values. Source and method refs remain pinned. This closes the arbitrary equal-token acceptance gap for **declared bound numeric fields**, not authenticity or completeness of a real-world source universe. Explicit TOKEN context fields preserve categorical source values under typed axes, complete support and source receipts; same-model pairing is checked when model IDs are declared on both cases. Unexecuted external reports carry declared value kind/unit/basis and oracle without numeric value. CL24 exercises a narrow original P5 projection and refuses weather/model drift and fabricated report value; no categorical value is passed to native math.
Ledger: use unchanged N7 contribution table for row coverage and atomic identity checks. Global event identity binds case, event key, actual qualified coordinate and source. Each contribution binds its observable/case/coordinate, event; aliases cannot defeat event duplicate checks. Propagate coordinate multiset over admitted native expression tree, sums, joins, shift/windows and selected cases; forward through upstream slots. Addition/subtraction/negation preserve occurrence lineage, multiplication/division permitted only with contribution-free factors/denominators; nonlinear contribution products/powers refuse. DISJOINT versus ALLOW_REUSE explicit; exact required event sets and global disjointness tested. Numeric output value alone is not evidence of valid aggregation. CBA-specific original P5 oracle replay remains independent; full original event/counterfactual-to-output projection not yet validated. No missing expected events silently invented.
Source/license/access/reproducibility declared via pinned source bytes; actual authorization and authenticity NOT_PROVED. Converted input data require raw values, explicit factor/rule and matching converted snapshot; reuse R1 monetary conversion. No data quality approval inferred from hash matching.

## 5. Identity, comparison and evidence (BLK-06)
Three notions: native math canonical bytes and package hash; semantic projection using native canonical spec, qualified types and scope, ordered binders/chronology, method definition, graph/frame policies and source refs; audit/source identity retains exact received bytes and all pins/receipts. Definition/instance each separately pinned; version tags included. Remove only native documented description fields from semantic projection. Unordered defined collections sorted by qualified ID, domain sets and partitions by member, contribution key axes normalized; ordered axes, chronological and quantifier order kept. No general rewrite proof, arbitrary doc-field removal, semantic equivalence claim, alias rewriting or approved override. Full outer projection normalization beyond explicitly classified fields not established. 
Comparison: distinct declared model implementation refs, typed common observations, actual native metric dependencies, tolerance parameter (same quantity and nonnegative range), decision assertion, sensitivity axes, and explicit selection rule. CL23 shows scenario-wise metric [0,-1] with tolerance 1. E3 finite sample only, not universal; E4 never proved by numeric agreement; E5 remains a conditional variation/evidence claim. Actual independent implementations and empirical robustness/variance decomposition not executed. Selection policy is declaration, no multiple-optimum execution or universal comparison proof. 
All 105 original traceability IDs and 20 MS-K criteria are preserved, with separate closure evidence and limits in requirement_traceability.csv. No score aggregation. 58 original test identities and 116 full A/B paths are preserved, 0 full paths executed in C2. Original domain oracles, R1, C1 and C2 tests are actual native regression, not C3 evidence. The controlled language is not a general formal proof of E2–E5 or real model conformity.

## 6. Reuse, versioning and remaining boundaries
No new native mathematical grammar, AST, canonicalizer, solver, code generator or upstream fork. New modules are semantic binders/adapters and finite scientific consumers. R1/C1/legacy code preserved; only original C2 interface and methods adapted to reuse static checks. All native dependency pins unchanged. New versioned outer schemas are research candidates with strict reimport; original outer package remains valid for original tests. No silent legacy migration or backwards compatibility claim beyond executed regressions. General authority conflict resolution, actual source-universe completeness, original P5 contribution/discounting-to-native-output context, full variance/selection semantics and structured diagnostics remain concrete gaps for unrestricted C2 requirement closure. CL24 preserves P5 rates, opaque fields and pending reports for the explicitly declared projection. No broad architecture research is justified. See gate_status.json for actual final gate decision, not inferred from passing tests.
