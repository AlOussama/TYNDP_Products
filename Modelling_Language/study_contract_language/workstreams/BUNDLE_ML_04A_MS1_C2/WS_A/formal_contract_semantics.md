# Formal external semantics
For environment e, admissible request r and externally observable trace y, write A(e,r) for data/technical/environment assumptions. Safety means every allowed trace under A satisfies G; capability means for every admissible request there exists an admissible response witness under A. Service additionally requires evidence that the actual implementation supplies a permitted response, not simply that a response exists. A feasible-set proof and a trace observation are different evidence. Conditional obligation uses applicability guard plus A; FALSE guard yields NOT_APPLICABLE only after complete static validation, UNKNOWN guard yields BLOCKED. False assumptions yield outside applicability, not successful guarantees. If the admitted request set is empty or completeness is unproved, capability must not be certified. Prohibition requires absence of prohibited behavior; permission is never a mandatory witness. Variation is an explicitly scoped allowed choice with a disclosure receipt. 
 
Bool3 uses strong Kleene: NOT T=F, NOT F=T, NOT U=U. AND with F is F, AND(T,T)=T, other results U. OR with T is T, OR(F,F)=F, other results U. Quantifiers over finite nonempty declared sets are AND/OR folds. Unknown reasons (missing data, missing evidence, unresolved authority) are distinct receipt fields; NOT_APPLICABLE is not a truth value. Native conditions are binary on complete data only. Static admission precedes any guard, including FALSE. A finite counterexample can refute a particular claim within the admitted scope; a finite positive witness does not prove a universal property over unobserved model behaviors.
 
Formal model freedom: project internal model solutions through an explicit observable map pi to contract traces. External equivalence requires same allowed/required external behaviors under same assumptions; equality on finite test points alone is weaker. Feasible-set equivalence requires equality of projected feasible sets and mathematical formulation equivalence requires a proved correspondence including objectives where relevant. No such general proof is claimed.
