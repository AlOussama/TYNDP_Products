# Concrete research syntax
The outer syntax is the strict JSON record described by schemas/external_contract.schema.json; native mathematics is a mathspec canonical package string, not an outer AST. A typical finite assertion is {id: "assertion:exchange", role: "SAFETY_GUARANTEE", modality: "MUST", predicate: {predicate_id: "pred:exchange_ok", role: "PREDICATE", axes: ["domain:t"], scope_id: "scope:research"}, binders: [{axis:"domain:t", kind:"time", quantifier:"FORALL"}], guard:"TRUE", authority:"OWNER_TBD"}. The example is illustrative; the executable test constructs exact qualified IDs from the native package. Each binder resolves exactly one declared axis. Binder order is significant; native axis order is not quantifier order. Additional fields rejected. No raw operator syntax or bypass. Full R1 source syntaxes A/B are frozen and not replaced by this example. See contract.py and test_contract.py.
