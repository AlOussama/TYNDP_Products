# Identity policy
Separate native canonical byte identity, versioned semantic projection, original source identity and audit identity. The bounded ABL08 projection removes ONLY top-level native description from an admitted package, reruns native canonicalization, and retains the complete semantic binding including symbol roles, quantity, context, method and scope. No arbitrary recursive removal of description or unknown extensions. Nested documentation policy remains unadmitted as an identity equivalence rule. Native bytes and source remain immutable. A bounded ABL06 legacy migration receipt retains original source bytes, exact source hash, bound native audit and legacy target audit; unsupported mapping remains rejected. This is a linked audit receipt, not a proof of lossless translation or equality of all semantics.
