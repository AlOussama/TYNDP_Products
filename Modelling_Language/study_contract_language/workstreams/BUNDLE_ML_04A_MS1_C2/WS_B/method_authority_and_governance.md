# Authority and governance
RESEARCH_ASSUMPTION and OWNER_TBD are retained. The generic C2 path verifies declared source bytes/hash, typed binding, and exact context pins, not publication authenticity or owner approval. For R1 original migration reuse n2r.evaluate, n7.authority, verified_file and pinned trust manifest as legacy verification; do not make a legacy AST the mathematical authority. MS1 source bytes remain frozen Git blobs. An exact finite result never grants an owner decision, real-data approval or normative applicability. Research bound on elapsed period count 0..99 is an admission restriction for the experiment, not a redefinition of a method or a policy default. The native affine exponent range is -100..100, checked statically and actual data range checked. Unknown authority stays blocked for conformance.
