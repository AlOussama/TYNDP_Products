# StudyProfile and binding
Study has id, version, profile identity, package identity, data-context identity, case-context identity and OWNER_TBD. Each is verified against actual admitted objects, not a bare caller assertion. Data changes require new pinned context; a method swap requires a changed profile identity and study binding. This bounded profile admits only one method per study; multiple methods, source approval allowlists, observable/output projection and comprehensive data snapshot governance remain open. No CBA-specific rules embedded. No implicit default parameters or conversion.
