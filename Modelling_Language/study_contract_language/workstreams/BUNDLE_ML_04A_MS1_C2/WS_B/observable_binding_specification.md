# Observable and output binding
Native symbol signatures carry qualified id, native name, dtype, ordered axis identities, role and physical quantity. Input and method parameter sets cover the native signature exactly; source bytes and study context hashes are checked. Native expression symbols are all typed; optional explicit output_contract partitions derived symbols into external outputs and intermediates, with no duplicates or missing symbols. Missing output partition means no external-output claim, not automatic promotion of all intermediates. Ledger contributions bind the actual observable id and case. Full R1 referent/projection adapter, multi-method dependency graph, external output authority and complete observation witness remain open. Tests B01/B06/B07/B09/B10.
