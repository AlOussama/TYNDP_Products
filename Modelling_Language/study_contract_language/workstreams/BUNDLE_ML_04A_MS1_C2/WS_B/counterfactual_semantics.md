# Counterfactual
Reference and alternative must be distinct typed series with identical quantity, price basis and axis signatures. Each required pair is matched exactly once. Exogenous context is content-addressed and must match across both cases. Permitted project changes must be explicitly specified by an authorized method profile. Equality of supplied context hashes is not evidence that every relevant exogenous field has been included. R1 n2r checks actual counterfactual relation, context and case coverage; the C2 bounded pair adapter validates actual supplied context and typed pair, but does not yet bind full original R1 case/referent relationships or allowed project-change coverage. Arithmetic difference alone is not a valid counterfactual.
