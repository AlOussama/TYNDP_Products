# Formal semantics — bounded executable and target distinction
Let E be admissible environments, R(e) requests, Y(e,r) response traces and Obs projection. The intended external safety obligation requires every actual trace under A to satisfy G; capability is forall admissible r exists y satisfying G, and service requires an actual response witness rather than feasible existence. A finite counterexample refutes the evaluated claim under observed assumptions; positive finite data do not establish coverage of E, R or Y. Model contract equivalence is equality of external obligations and allowed/required projected behaviors, not equality of native hashes.

Truth lattice FALSE < UNKNOWN < TRUE: conjunction min, disjunction max, negation reverses. For finite nonempty declared support, forall=meet and exists=join in explicit order. Applicability is not a truth value. Validate package and supplied data before applicability; inactive invalid constructs rejected statically. Native data assumptions use complete binary holds/where, forall only. False assumptions yield OUTSIDE_ASSUMPTIONS; Unknown/nonapplicable assumptions yield BLOCKED_ASSUMPTIONS. Finite false guarantee after observed assumptions yields FINITE_COUNTEREXAMPLE; all inapplicable guarantees NOT_APPLICABLE. Permission MAY is not an obligation. Prohibition MUST_NOT negates native predicate at each point. Complete policy/authority/variation semantics are not proved.

Quantity algebra requires exact tagged dimensions, carrier atoms, basis and convention. Native parser and Program define mathematical expressions; static admissibility is necessary not sufficient for a finite evaluator. No implicit default conversion or unknown-to-zero.

Method validity requires signature, source hash, complete support, parameter ranges, declared weight policy, typed pair and context, output coverage and where declared ledger identity/lineage. Counterfactual equality of supplied context hashes is not full exogeneity. Disjoint lineage counts atomic events; overlap requires explicit ALLOW_REUSE.
